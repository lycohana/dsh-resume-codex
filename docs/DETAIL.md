# 从 Codex 继续

在新建会话页（工作区 / 模式所在的那一行）增加一个「从 Codex 继续」入口。选一个本机 Codex 会话后，DSH 会：

1. 读取 `~/.codex/sessions`（或 `CODEX_HOME`）下的 rollout 记录；
2. 把对话内容转换成 DSH 会话历史，包含最近一次可读的 Codex 压缩（compaction）摘要；
3. 把 Codex 会话的工作目录登记为工作区，让新会话在其中继续；
4. 打开新会话，直接接着聊。

Codex 文件只读，不会修改，也不会向 Codex 发送任何内容；不需要 Codex 额度。

## 用法

1. 打开新建会话页，点「从 Codex 继续」。
2. 在弹窗中选择会话（可按标题 / 目录 / 模型搜索，可只看当前目录）。
3. 选择导入范围：
   - **智能（摘要 + 最近 30 轮）**：默认，体积小，适合日常续聊；
   - **摘要 + 最近 50 轮**：上下文更长；
   - **全部对话**：完整导入，文件很大时会从最早处截断。
4. 需要命令历史时打开「包含工具调用」。
5. 点「继续」，DSH 会创建并打开新会话。

## 行为细节

- 会话标题取自 Codex 的首条用户消息；时间取 rollout 的创建时间。
- 智能模式只使用以 `ccswitch-compaction-v1:` 开头的明文摘要（base64 UTF-8）。OpenAI 等加密格式的 compaction 内容是二进制，不能当文本解码；遇到时回退到最近一份可读摘要，并从该摘要之后导入消息，避免把密文当正文。
- 工具调用默认不进入历史；打开后命令与输出会以工具记录形式导入，单条输出默认截断到 12 000 字符。
- 原工作目录不存在时，回退到当前工作目录并给出警告。
- 已导入过的会话在列表中带「已导入」标记，可再次导入。

## 配置

在插件行的 `config` 中可选设置：

| 键 | 默认值 | 说明 |
|---|---|---|
| `codexHome` | `$CODEX_HOME` 或 `~/.codex` | Codex 数据目录 |
| `maxSessions` | `500` | 列表最多读取的会话数 |
| `maxTurns` | `30` | 智能模式保留的最近轮数 |
| `maxChars` | `240000` | 智能模式的字符预算 |
| `maxFullChars` | `4000000` | 全部模式的字符预算 |
| `maxImportFileBytes` | `67108864` | 单个 rollout 文件大小上限 |
| `toolResultMaxChars` | `12000` | 单条命令输出上限 |

## 限制

- 只导入文本；图片与附件以 `[图片]` / `[文件]` 占位。
- Codex 的加密推理内容（`reasoning`）不会导入。
- 导入是不可撤销的会话语义：生成的会话独立存在，不跟随 Codex 后续变化。
